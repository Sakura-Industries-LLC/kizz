# The paths that the coverage-test step must record under the task directory, and no others.
#
# Each entry is one line of fields separated by spaces:
#
#     PATH KINDS STATE PLATFORM SOURCE...
#
# PATH is relative to the task directory, as the tracer reports it: `.` components and repeated
# separators are removed, and `..` components are kept.
#
# KINDS joins with `+` the access kinds that "What is recorded" names: read, probe, list, write and exec.
#
# STATE is the type of the path's state when the step ended, as "Path states" names it:
#
# * absent;
# * file, a regular file that was only checked or written, without a hash;
# * file+hash, a regular file that was read or run, with the hash of its content;
# * dir, a directory that was only opened or checked;
# * dir+listing, a directory that was listed, with its entries;
# * fifo, socket, char-device or block-device;
# * symlink:TARGET:POINTEE, a symbolic link with its target and the state of what it points to,
#   which is recorded with the kinds of the link's own entry.
#
# PLATFORM is where the path is touched: all, every platform, for the portable core; linux, for the Linux
# section; or linux-x86_64, for the code that the Linux section compiles only where a call exists that
# aarch64 lacks, such as open, stat or getdents.
#
# Each SOURCE is a call that touches the path in the run, as ORIGIN:NAME:OUTCOME:KINDS.
# ORIGIN is sys, for a tracked system call that coverage.c makes through syscall(); libc, for a function of
# the C library; kizz, for kizz's own start of the program with a traced execve; or kernel, for a file that the
# kernel loads to run a program without a system call of its own: interpreter, the interpreter that the #! line
# of a script that a process runs names, and interpreter_of_interpreter, the interpreter of an interpreter that
# is a script itself, at any depth.
# OUTCOME is ok, or the error the call failed with; KINDS are the kinds the call adds.
# A call that succeeds adds the kinds of "What is recorded", as the Linux tracer decodes them since Step 4:
# opening for reading reads, opening for writing, creating or truncating writes, and O_DIRECTORY or O_PATH
# only probes.
# A call that fails, with ENOENT or another error, adds a probe of each of its paths, because its lookup
# happened.
#
# The paths that the Linux section creates under out/linux/made-link, a symbolic link to out/linux/made, are
# recorded under the link's name; the call that a group tests then works on the path under out/linux/made,
# or on a descriptor that names it, so it is that path's only source.

# The program, which kizz starts with execve, the portable core's child runs again with execv, and the kernel
# runs as the interpreter of the script in/linux/interp/inner.
